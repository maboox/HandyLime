# HandyLime — راهنمای فارسی

ابزاری برای تبدیل و ویرایش فایل‌ها در ویندوز، با پردازش محلی، چرخ انتخاب کنار نشانگر و تم روشن/تیره.

## دانلود

از صفحهٔ **[Releases](https://github.com/maboox/HandyLime/releases/latest)** فقط یکی از دو نسخهٔ برنامه را بگیرید:

| نسخه | مناسب برای | پیش‌نیاز |
|---|---|---|
| **[Portable](https://github.com/maboox/HandyLime/releases/latest/download/HandyLime-windows-x64.zip)** | استخراج و اجرای مستقیم | دات‌نت همراه برنامه است |
| **[Lite](https://github.com/maboox/HandyLime/releases/latest/download/HandyLime-windows-x64-lite.zip)** | دانلود کم‌حجم‌تر | نصب **[.NET Desktop Runtime 10 برای Windows x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)** |

امکانات و کیفیت خروجی هر دو یکسان است. نسخهٔ Lite از دات‌نت نصب‌شدهٔ سیستم استفاده می‌کند؛ نسخهٔ معمولی .NET Runtime یا ASP.NET Runtime کافی نیست.

فایل **corresponding-source** سورس کتابخانه‌های جانبی برای توسعه و بازنشر است و **برای اجرای برنامه لازم نیست**. فایل‌های `.sha256` فقط برای بررسی اختیاری سلامت دانلود هستند.

## شروع کار

1. تمام محتویات ZIP برنامه را استخراج و **HandyLime.exe** را اجرا کنید؛ فایل EXE را از فایل‌های کنارش جدا نکنید.
2. فایل‌ها را داخل پنجره بکشید یا از **Add files** و **Ctrl+O** استفاده کنید. کپی فایل از Explorer و زدن **Ctrl+V** هم کار می‌کند.
3. فرمت یا ابزار را انتخاب کنید و نسخهٔ جدید را ذخیره کنید. پنجرهٔ **Activity** پیشرفت، لغو، خطا و دکمهٔ بازکردن خروجی را نشان می‌دهد.
4. برای ویدیو و صدا، **FFmpeg و FFprobe** را از **Settings → Conversion engines** نصب یا معرفی کنید. Office به LibreOffice و مسیرهای Markdown/EPUB به Pandoc نیاز دارند. [راهنمای موتورهای جانبی](ENGINES.md).

از Windows 11 x64 یا نسخه و بیلد پشتیبانی‌شدهٔ Windows 10 استفاده کنید. این نسخه فعلاً پیش‌نمایش و بدون امضای تجاری است؛ ممکن است ویندوز پیام اعتبار ناشر نمایش دهد.

## چرخ انتخاب

فایل را از Explorer بکشید، کمی حرکت دهید و سپس کلید را بزنید:

- **Shift:** تبدیل فرمت
- **Alt:** ابزارهای ویرایش
- **Ctrl:** عملیات فایل
- **Tab:** صفحهٔ بعدی گزینه‌ها
- **زدن دوبارهٔ همان کلید:** بستن چرخ با ادامهٔ درگ

کلید را رها کنید و با نگه‌داشتن ماوس، فایل را روی گزینهٔ موردنظر بیندازید. مرکز چرخ لغو می‌کند. دکمهٔ **Open wheel** هم برای فایل‌های داخل پنجره موجود است.

## امکانات

- **عکس:** تبدیل، تغییر اندازه، کراپ، چرخش، تنظیم نور و رنگ، علامت‌گذاری، زمینه، کلاژ و متادیتا.
- **ویدیو و صدا:** تبدیل، GIF، برش، تقسیم، کراپ، مرتب‌کردن و اتصال کلیپ‌ها، سرعت و استخراج فریم.
- **PDF و سند:** ترکیب، تقسیم، ترتیب و چرخش صفحات، خروجی تصویر و متن و تبدیل اسناد با موتورهای جانبی.
- **فایل:** ZIP/TAR، هش، کپی مسیر و قفسهٔ شناور فایل‌ها.

جزئیات فرمت‌ها و محدودیت‌ها در [FORMATS.md](FORMATS.md) و راهنمای ویرایشگرها در [USAGE.md](USAGE.md) آمده است.

## نکته‌های کاربردی

پردازش محلی است؛ حساب کاربری لازم نیست و فایل تبدیل برای سرور ارسال نمی‌شود. نصب موتورهای جانبی به اینترنت نیاز دارد.

خروجی‌ها به‌طور پیش‌فرض کنار فایل اصلی و با نام جدید ذخیره می‌شوند. عملیات جداگانهٔ **Move to…** پس از تأیید، محل فایل اصلی را تغییر می‌دهد.

تم را در **Settings → Appearance → Light / Dark / System** انتخاب کنید. بستن پنجره به‌طور پیش‌فرض برنامه را در Tray نگه می‌دارد؛ برای خروج کامل **Quit** را بزنید. این رفتار در تنظیمات قابل تغییر است.

این نسخه پیش‌نمایش است؛ اسناد پیچیده و کدک‌های خاص ممکن است محدودیت داشته باشند. پیش از حذف فایل اصلی، خروجی را بررسی کنید.
